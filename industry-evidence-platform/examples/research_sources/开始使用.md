# 数学建模测试集

本文件夹整理于2026-10-22。内容为待采集的权威公报网址清单、口径配置与来源目录，尚不是已经清洗好的数值CSV，也不代表模型已通过测试。

优先方向：全国粮食年度产量。棉花、油料为备选。

- 01_公报网址_2000-2025.txt：26个年度入口，建议先用。
- 02_公报网址_1978-2025.txt：48个年度入口，与前一份重叠，不应合并后当作74份独立材料。
- 配置_全国粮食.json、配置_全国棉花.json、配置_全国油料.json：分别使用一个研究方向。
- 来源目录.csv / 来源目录.json：年度、地址与核对状态。
- 先读说明.md：来源、配置加载方式及局限。

从项目根目录使用CLI前，将所选配置复制到项目config目录，并用--config指定。若复制为config/research-grain.json，示例为：

```powershell
.\.venv\Scripts\python.exe -m app.pipeline_cli --config config/research-grain.json --urls-file "examples/research_sources/01_公报网址_2000-2025.txt" --query "研究全国粮食年度总产量的发展趋势，仅使用全国全年粮食总产量，不混入分季节、分品种产量"
```

网页不会自动读取桌面配置。详细口径规则参见先读说明.md；其中的旧文件夹名“数学建模研究来源_20261022”是原始整理包，在本副本使用时将网址TXT路径改为本文件夹即可。

本次仅复制整理文件并核对清单，没有启动采集、训练或模型API。原始研究来源文件夹保留。
