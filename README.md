## 📖 关于本项目

本项目目标：做一个**带长期记忆的 DeepSeek 对话助手**——对话内容持续沉淀为本地记忆，
让 AI "记得住事"，并在此基础上逐步扩展文件交互、图形界面与平台接入。

本仓库完整记录项目从雏形到成型的每一步：所有版本按时间顺序依次提交，每个里程碑
版本都附带一份**当时的项目说明（即本 README）**——检出任一提交，即可还原那个
年代码与文档的完整面貌。

## 📋 仓库约定

- `.env` 存放 `DEEPSEEK_API_KEY`，已被 gitignore，不入库
- `venv_light/`、`__pycache__/`、运行生成的输出文件不纳入版本管理
- `废案及历史版本/` 集中存放已被新版本取代的旧文件
