# 🎨 Scratch 3D：一支画笔变出的 3D 世界！

> 🖌️ 没有贴图包，没有神秘扩展，没有一行真正的代码——
> 只有一支**画笔**、60 根**激光线**，和一个会走迷宫的**小方块**！

## 🎮 怎么玩

用 Scratch 编辑器打开 `Scratch 3D.sb3`，点击绿旗 🚩，你就走进了 3D 迷宫！

| 按键 | 动作 |
|:---:|:---:|
| `W` / `↑` | 🚶 向前走 |
| `S` / `↓` | 🔙 往后退 |
| `A` / `D` | ↔️ 左右平移 |
| `←` / `→` | 🔄 平移 + 转身 15° |

> [!TIP]
> 试试按住 `W` 和 `D` 一起走——斜着走路也是可以的！

## 🧸 项目里住着谁？

这个项目一共有 5 个角色，其中 3 个从头到尾都是**隐身**的！

| 角色 | 它在干什么 | 小秘密 |
|------|-----------|--------|
| 🏰 `level` | 一张隐形的地图 | 灰色的 SVG 画，幽灵效果 100%，专门负责"撞墙检测" |
| 🌈 `level color` | 地图的"影子分身" | 和 level 长得几乎一样，但偷偷挪了一点点，用来给墙涂颜色 |
| 🏃 `player` | 你的化身 | 全程隐身！其实只是一个 4×4 像素的小方块在地图里跑 |
| 🖌️ `RayCaster` | 魔法画家 | 每一帧发射 60 根射线，把整个 3D 画面一根线一根线画出来 |
| 🖼️ 舞台 | 背景板 | 渐变背景假装自己是天花板和地板 |

## 🪄 3D 是怎么变出来的？

想象你闭着眼睛，拿一把**手电筒**对着房间扫一圈。每束光照到墙就停下来，你用手量一量光走了多远——**墙越近，看起来就越大**！Scratch 做的事情一模一样。

### 🔦 第一步：发射 60 根射线

魔法画家 `RayCaster` 站在玩家身边，从视野的最左边开始，每画完一根就向右转 1°，一共扫 60 次：

```
重复 (60) 次
    Singal Ray        ← 发射一根射线，画一列墙
    右转 (1) 度
```

每根射线在屏幕上画一条竖线。60 条 8 像素宽的竖线，正好铺满 480 像素宽的舞台！

### 📏 第二步：量出墙有多远

射线像小蚂蚁一样往前爬：大步走 2 步，撞到墙以后再小步退 0.5 步，稳稳停在墙边上。

```
重复直到 <碰到 level ?>      ← 大步冲！
    移动 (2) 步
重复直到 <没有碰到 level ?>  ← 小步退回来
    移动 (-0.5) 步
```

停下时"到 player 的距离"，就是这根激光撞墙的位置离你有多远。

### 🐟 第三步：治好"鱼的眼睛"

如果直接用刚才量到的距离，笔直的墙会**弯成一根香蕉** 🍌（真的会！很多教程都忘了这一步）。

治疗方法只要一行：乘一个余弦。

```
距离 = 距离 × cos(射线的方向 − 玩家的方向)
```

### 🧱 第四步：近大远小

画笔从上到下画一条竖线，高度 = 4000 ÷ 距离：

- 距离 20 → 墙高 200，撑满整个屏幕！😱
- 距离 100 → 墙高只有 40，缩在屏幕中间

这就是"近大远小"，3D 感就是这么来的。

### 🌫️ 第五步：越远越黑

```
笔的亮度 = 120 − 距离
```

像手电筒快没电了一样，墙越远越暗，最后慢慢沉进黑暗里。背景的天花板和地板用了**同样的渐变**（地平线是黑的），所以墙和背景能严丝合缝地接上，一点破绽都没有。

### 🎨 小秘密：墙为什么有两种颜色？

还记得"影子分身" `level color` 吗？它把每面墙都往一边挤出了约 4 像素的小边边。射线停下来以后摸一摸：

- 摸得到小边边 → 涂**偏蓝**的颜色（色号 58）
- 摸不到 → 涂**偏青**的颜色（色号 53）

朝不同方向的墙有了不同颜色，再配上远近的明暗，画面立刻就有层次啦！

### 🚶 走路不穿墙的秘密

`player` 走路时分两半：先迈"横着的脚"，再迈"竖着的脚"。每只脚伸出去之前先试试，碰到墙就赶紧缩回来：

```
定义 Try move (dx) (dy)
    将 x 坐标增加 (dx)
    将 y 坐标增加 (dy)
    如果 <碰到 level ?> 那么
        将 x 坐标增加 (-dx)   ← 收回！
        将 y 坐标增加 (-dy)
```

所以你可以贴着墙**滑着走**，永远不会被卡在墙里～

`#` 是墙，`P` 是你出生的地方（地图中上方，面向 45°）。里面有东倒西歪的围墙、一根大圆柱，还有 4 个小圆点——小圆点也会被当成墙，画成细细的小柱子哦！

## 🧪 动手试一试

打开编辑器，找到这些变量，改改看会发生什么：

| 你想让…… | 改这个变量 | 会发生什么 🤩 |
|----------|-----------|--------------|
| 画面更清楚 | `RES` 改成 4 | 每帧画 120 根线，电脑会有点喘 😤 |
| 跑得更流畅 | `RES` 改成 16 | 画面变成大马赛克 |
| 视野更宽 | `FOV` 改成 90 | 像章鱼的眼睛 👀 |
| 看清走廊尽头 | 射线步长 2 改成 5 | 走廊更远也看得见 |

> [!WARNING]
> 玩完了记得改回原来的数字（`RES=8`、`FOV=60`）哦！

## 🤔 你知道吗？

- 🖌️ 你看到的一切都是画笔画出来的——三个主要角色从头到尾都是隐身的！
- 📨 玩家每走一小步就广播一次"该画画了"；如果画家还没画完，新的广播会被自动忽略，所以活儿不会越堆越多。
- 🍌 把鱼眼校正那一行 `cos` 删掉，墙壁真的会变弯——去试试看！
- 🐛 `Singal Ray` 其实拼错了，正确的单词是 `Single`（一根）。你能在编辑器里找到它吗？
